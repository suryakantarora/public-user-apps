# Installation Guide (Android)

Follow these steps to install an APK downloaded from this repository.

## 📥 Step 1: Download the APK

1. Open the **Releases** section of this repository.
2. Download the latest `.apk` file to your Android device.

---

## 🔐 Step 2: Allow Installation from Unknown Sources

### Android 8.0 (Oreo) and Later

1. Open the downloaded APK.
2. If prompted, tap **Settings**.
3. Enable **Allow from this source** for your browser or file manager.
4. Go back and continue the installation.

### Android 7.0 (Nougat) and Earlier

1. Open **Settings** → **Security**.
2. Enable **Unknown Sources**.
3. Confirm the warning message.

> **Note:** Menu names may vary depending on your device manufacturer and Android version.

---

## 📲 Step 3: Install the APK

1. Locate the downloaded APK using your **Files** app or notification.
2. Tap the APK file.
3. Tap **Install**.
4. Wait for the installation to complete.
5. Tap **Open** to launch the app.

---

## 🔄 Updating the App

To update the app:

1. Download the latest APK from the **Releases** page.
2. Install it over the existing version.
3. Your data will usually be preserved unless otherwise stated.

---

## ❗ Troubleshooting

### "App not installed"

- Ensure the APK downloaded completely.
- Check that you have enough storage space.
- Uninstall older versions if they were signed with a different certificate.

### Installation blocked

- Verify that **Allow from this source** is enabled.
- Try opening the APK using a different file manager.

### Google Play Protect Warning

Apps installed outside the Google Play Store may trigger a Play Protect warning. If you trust the source, you can choose to continue the installation.

---

Only install APKs from sources you trust. Review the repository and release notes before installing any application.
